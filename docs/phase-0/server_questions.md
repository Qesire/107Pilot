# 两台比赛服务器最小确认清单

## 应用节点

- 操作系统和架构；
- CPU、内存、磁盘；
- 是否有 root 或 sudo；
- 是否允许 Docker，若不允许，是否允许 systemd 用户服务；
- 可开放哪些端口；
- 是否有域名和 HTTPS；
- 是否能访问 Docker 宿主机；
- 是否能访问校内 LLM API。

## Docker 宿主机

- CPU、内存、磁盘；
- Docker/Compose 版本；
- 用户是否在 docker group；
- 是否可持久化 volume；
- 可开放哪些端口；
- 应用节点到其端口的网络连通性；
- 是否允许构建镜像；
- 是否允许提前导入离线镜像；
- 服务器重启策略。

## 两台机器之间

- 固定 IP 或主机名；
- 防火墙；
- 是否能使用 TLS；
- 时间同步；
- 最大文件传输；
- 是否共享任何目录；
- 若不共享，Evidence 通过 API 还是对象包传输。
